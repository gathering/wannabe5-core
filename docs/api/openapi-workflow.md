# OpenAPI Workflow

## Source

OpenAPI is generated by Scramble from the Laravel route/controller surface and committed as `openapi.json`. That includes native `/api/{service}` domains and core resources. Compatibility `/api/ms/*` closures may appear sparsely; treat `config/backend_compat_routes.php` + contract tests as the adapter source of truth.

Native path summary: `docs/api/native-surfaces.md`.

## Deterministic Check

```bash
composer run-script check:openapi
```

This runs:

1. `php artisan scramble:analyze`
2. `php artisan scramble:export --path=openapi-ci.json`
3. `diff openapi.json openapi-ci.json`

If diff fails, regenerate and commit updated `openapi.json` (`php artisan scramble:export`).

## CI Gate

CI runs the same check and fails on drift.
