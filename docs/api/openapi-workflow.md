# OpenAPI Workflow

## Source

OpenAPI is generated by Scramble from the Laravel route/controller surface and committed as `openapi.json`. That includes native `/api/{service}` domains and core resources. Compatibility `/api/ms/*` closures may appear sparsely; treat `config/backend_compat_routes.php` + contract tests as the adapter source of truth.

Native path summary: `docs/api/native-surfaces.md`.

## Deterministic Check

```bash
composer run-script check:openapi
```

This runs:

1. `APP_URL=http://localhost:8000` (forced so residual `url()` usage cannot pick up local-stack hosts)
2. `php artisan scramble:analyze`
3. `php artisan scramble:export --path=openapi-ci.json`
4. Assert `servers[0].url` is `http://localhost:8000/api` (also pinned in `config/scramble.php`)
5. `diff openapi.json openapi-ci.json`

If diff fails, regenerate and commit updated `openapi.json`:

```bash
APP_URL=http://localhost:8000 php artisan scramble:export
```

Do not commit a `servers[].url` that uses `wannabe5.gathering.org` — CI will fail.

## CI Gate

CI runs the same check and fails on drift.
